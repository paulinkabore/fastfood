# Fast-Food QR Management

Plateforme de gestion de fast-food avec commande par QR code.

## Stack
React + Vite + TypeScript + Tailwind | Node.js + Express + TypeScript | PostgreSQL + Prisma | Socket.IO

## Structure
- `frontend/` : application React
- `backend/` : API Express
- `database/` : scripts SQL complémentaires
- `docs/` : cahier des charges, API, diagrammes
